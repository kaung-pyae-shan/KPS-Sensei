# KPS-Sensei

A clean, fast Japanese learning app that turns a kanji, word, or grammar point into one scannable context card.

Live cards are generated by **Google Gemini 3.5 Flash-Lite** with a strict JSON response schema. No backend, no database — your cards and API key stay in this browser's `localStorage`.

## What a card gives you

- **Header** — term, reading, category, and a meaning of five words or fewer.
- **Vibe & context** — register badges plus one sentence on where to use it.
- **How to use** — a compact pattern, formula, or collocation.
- **Real-world examples** — exactly two short sentences (casual and polite) with clean `<ruby>` furigana and Japanese text-to-speech.
- **English or Burmese** — every explanation, nuance sentence, pattern note, and example translation is written in both languages. Use the **English / မြန်မာ** switch above the card to choose which one you see.
- **Local library** — recent cards are saved automatically (last 50), can be starred, and stay private to this browser.

## Quick start

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually http://localhost:5173).

The app starts in **Demo mode** with three ready-made cards:

| Query | Category |
| --- | --- |
| `届` | Kanji |
| `遠慮` | Kotoba |
| `〜てしまう` | Grammar |

Click a sample chip or search one of those terms to try the full card experience without a key.

## Connect Gemini

1. Open **Settings** (the sliders icon) and choose **Get a free key**.
2. Create a key in [Google AI Studio](https://aistudio.google.com/app/apikey).
3. Paste it into the app and save.

Requests go directly from your browser to Google's Gemini API using `gemini-3.5-flash-lite`, `responseMimeType: "application/json"`, and a strict `responseSchema`. If that model isn't enabled for your key, the app automatically tries `gemini-3.8-flash`, then `gemini-3.1-flash-lite`, then `gemini-2.5-flash` before reporting an error. The key is never sent to any other server. Remove the saved key at any time to return to Demo mode.

## Stack

- React 19 + TypeScript (strict)
- Vite 8
- Tailwind CSS 4
- Noto Sans JP + Noto Sans Myanmar via Google Fonts
- Web Speech API (`speechSynthesis`, `ja-JP`)
- Browser `localStorage` only

## Project layout

```
src/
  components/     SearchBar, ContextCard, RubyText, HistoryDrawer, ApiKeyModal, …
  data/demo.ts    The three pre-loaded demo cards
  lib/            Storage and small utilities
  services/       Gemini request, JSON schema, response normalization
  types.ts        Shared card and history types
  App.tsx         App state, search flow, local persistence
```
